Launch Radar — a comps-fitted token launch radar. It reads a sealed DefiLlama snapshot, fits a size curve to the protocols whose token already trades, ranks 226 pre-token protocols by implied value, and gives each one a farm plan netted to the dollar.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
